# Targeted learning plans

Pick the doorway that matches your curiosity.

- **Building something?** Start with an application mission and follow the technologies that can help.
- **Studying one part of the Workshop?** Start with a technology route and see where it fits in a working application.

These plans are guided trails through separate repositories. They teach you what to try, what to observe, and which project owns the deeper reference. They do not imply every linked project is already integrated.

## A useful way to travel

`Mission → smallest useful model → Workshop capability → visible result → evidence → deeper project reference`

Each plan includes checkpoints. Pause at each one and explain what changed, which component owned it, and what the evidence proves. If the result surprises you, [find the first divergence](../DEBUG_A_RESULT.md).

The learning center follows the [FSM_COS documentation standard](https://github.com/TrentBest/TheSingularityWorkshop.FSM_COS/blob/master/DOCUMENTATION_STANDARD.md): clear purpose and boundaries, progression for the reader, honest implementation status, visual explanation where useful, and source links for deeper reading.
