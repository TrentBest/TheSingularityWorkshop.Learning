How to read this space

Every picture has a boundary

What does the interactive oscillator demonstrate?

It demonstrates a bounded-value rule in browser JavaScript so you can vary parameters and observe the sequence. It does not prove that the FSM_API implementation ran. The problem lesson identifies upstream checks and the source recipe separately.

What does GUI.SVG do?

GUI.SVG renders a semantic GUI scene into SVG. It does not own the state machine, simulation clock, or arbitrary interaction. Each example names the source of its data and motion.

Are the journey stages one integrated application?

No. They are distinct examples arranged in a useful learning order. Follow each project’s setup and implementation-status guidance before combining components.

This explorer is a visual front door to the learning guides. The guides teach workflows; linked repositories remain authoritative for APIs, setup, and current implementation behavior.
