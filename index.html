How to read this space

Every picture has a boundary

Where does the live demonstration run?

The live FSM demonstration runs in the Workshop WebApp. This Learning Center guides the exploration and points to the WebApp source; it does not recreate or simulate the host application.

What does GUI.SVG do?

GUI.SVG renders semantic GUI scenes as scalable SVG. In the live exercise, FSM_API drives the state changes and the visualization presents the resulting values.

How should I use the learning path?

Start with a problem, operate the matching live Workshop experience where available, then use each focused guide to trace the behavior to its owning repository and source.

This explorer is a visual front door to the learning guides. The guides teach workflows; linked repositories remain authoritative for APIs, setup, and current implementation behavior.
